Algorithm

How the Simulation Works

BFS

Breadth-First Search

Each robot uses BFS to find the shortest path. The algorithm explores cells level by level, guaranteeing minimum steps.

📏

Manhattan Distance

When multiple robots are idle, the nearest one is chosen using Manhattan distance: |x₁−x₂| + |y₁−y₂|.

⏱

Discrete Time Steps

The simulation advances tick by tick. Each tick, every robot moves one cell along its pre-computed path.

🔄

Continuous Orders

Once a robot delivers, a new order is instantly generated — keeping all robots busy and measuring steady-state performance.
