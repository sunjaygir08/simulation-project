Core Features

What Makes It Smart

Combining AI path-finding, real-time simulation, and performance analytics into one system.

🤖

Autonomous Robots

Multiple robots operate concurrently, each assigned orders and navigating the warehouse grid without human input.

🗺️

BFS Pathfinding

Breadth-First Search guarantees the shortest collision-free path from robot position to shelf and back to exit.

📦

Order Management

Orders are generated dynamically and assigned to the nearest idle robot, minimising wait time and improving throughput.

📊

Performance Metrics

Live tracking of robot utilisation, order completion time, system efficiency, and distance travelled per delivery.

⚡

Discrete Simulation

Time-step driven simulation engine ensures accurate modelling of concurrent robot movement and order queue processing.

📈

Experiment Analysis

Three controlled experiments compare different robot counts, order volumes, and grid sizes with chart-based results.
