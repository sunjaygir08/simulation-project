About This Project

Design, Modelling, and Simulation of an AI-Based Smart Warehouse Automation System.

Project Overview

This project addresses the challenges faced by modern warehouses: inefficient item retrieval, long order processing times, high operational costs, and resource underutilisation.

We designed and simulated a Smart Warehouse Automation System where autonomous robots pick and deliver items within a grid-based environment using AI optimisation algorithms.

The simulation analyses key performance parameters including order completion time, robot utilisation, waiting time, distance travelled, and system efficiency.

Problem Statement

Manual warehouse systems are slow and prone to human error. Automated warehouses using robots and intelligent systems dramatically improve efficiency and reduce operational costs.

This Complex Engineering Problem (CEP) was designed to evaluate warehouse performance and improve efficiency using modelling and simulation techniques aligned with CLO 3, C5, and PLO 4.

Mathematical Model

Grid Representation: N × M matrix

Distance: Manhattan Distance = |x₁−x₂| + |y₁−y₂|

Completion Time: Delivery Time − Generation Time

Utilisation: Active Time / Total Simulation Time

Efficiency: Completed Orders / Total Orders × 100

System Architecture

warehouse.py

Generates the N×M grid, places shelves randomly, sets exit point. Provides walkability checks for BFS.

robot.py

Autonomous agent with BFS pathfinder, Manhattan distance calculator, and state machine (idle→moving→carrying).

order.py

Manages order lifecycle from generation to delivery. OrderGenerator creates orders at timed intervals.

simulation.py

Discrete-time engine. Each tick: generate order → assign robot → move robots → update metrics.

metrics.py

Calculates and reports all 5 performance metrics. Generates charts for the 3 controlled experiments.
