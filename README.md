## ⚙️ Setup Instructions

### 1. Install Python
Make sure Python 3.9 or higher is installed:
```bash
python --version
```
Download from: https://python.org

---

### 2. Create a Virtual Environment (Recommended)
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

---

### 3. Install Flask
```bash
pip install -r requirements.txt
```
Or manually:
```bash
pip install flask
```

---

### 4. Run the Project
```bash
python app.py
```

You should see:
```
 * Running on http://127.0.0.1:5000
 * Debug mode: on
```

---

### 5. Open in Browser
Visit: **http://127.0.0.1:5000**

## 📊 Key Features

- **5 KPI Cards** — active robots, orders, efficiency, inventory
- **3 Charts** — hourly throughput (line), order status (doughnut), robot utilisation (bar)
- **Live Simulation** — canvas animation of 4 robots navigating a 12×12 grid
- **AJAX Refresh** — dashboard refreshes data without page reload
- **Contact Form** — Flask POST with validation and flash messages
- **Responsive** — works on mobile and desktop

## 📌 Notes

- The dashboard uses **dummy/random data** generated by Flask each request.
- Click **"↻ Refresh Data"** on the dashboard to fetch new live stats via AJAX.
- The simulation runs fully in the browser using the **Canvas API** — no server needed.
- Contact form messages are validated server-side but **not emailed** (extend with Flask-Mail if needed).
